{% comment %} Shared « À étudier » marker for one comprehension question. Every surface that shows a question reuses this control, so a question can be marked from the test list, the correction page, a live attempt, or the results. It posts a normal form without JavaScript and is upgraded in place by comprehension-progress.js. Parameters: csrf_token — required because this partial is included with ``only``. marker — payload built by _comprehension_study_marker() in the views. next_url — same-origin path to return to when JavaScript is unavailable. variant — optional layout modifier ("row", "side", "quiz", "review", "list"). show_text — render the visible action label beside the icon. {% endcomment %}
